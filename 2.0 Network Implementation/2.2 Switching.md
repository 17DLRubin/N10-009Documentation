## VLANs
- VLAN (Virtual LAN)  
  A subgroup within a network that combines a group of devices from multiple physical LAN segments. Allowing them to communicate as if they were on the same physical LAN
- VLAN DB  
  A DB where VLAN configs are stored on a network device, such as a switch  
  Includes info like VLAN IDs and associated properties. Enabling the switch to organize and manage network traffic accordingly
- SVI (Switch Virtual Interface)  
  A virtual interface on a switch that provides layer 3 processing for VLANs  
  Allows the switch to route traffic between VLANs by assigning IDs to VLAN interfaces. Essentially enabling inter-VLAN routing on layer 2 switches

## Interface Configurations
- Interface Configurations  
  Involves setting various parameters on a network device's interface to optimize performance and functionality  
  Settings can include VLAN assignments, link aggregation, and physical properties like speed and duplex mode
- 802.1Q (Port Trunking)  
  A method of inserting a VLAN identifier into ethernet frames to distinguish between different VLANs on a trunk port  
  Allows multiple VLANs to share a single physical connection. Enabling efficient use of network resources and traffic segregation
- Native VLAN  
  The default VLAN on a trunk port that carries untagged traffic  
  Essential for ensuring that untagged traffic from older devices that don't support VLAN tagging is still routed correctly
- Voice VLAN  
  Designed to prioritize and separate voice traffic from other types of traffice  
  This specialization ensures QoS (Quality of Service) for VoIP communications.  
  Reduces latency, jitter, and packet loss for critical voice communications
- LACP (Link Aggregation Control Protocol)  
  Involves combining multiple network ports into a single group. Increasing bandwidth and providing redundancy for higher data throughput and reliability  
  Allows the consolidation of multiple links between switches or between switches and servers. Enhancing the overall network capacity and fault tolerance
- Speed  
  Denotes the data transfer rate of a network connection. Typically measured in Mbps or Gbps  
  Typically set to automatic. However, if the speeds do not match on both ends, the link won't work (no link light)
- Duplex  
  Refers to the communication mode of a network connection  
  Typically set to automatic or full duplex. However, if the duplex doesn't match on both ends, the link will work but at reduced efficiency
  * Full Duplex  
    Allows simultaneous two way communication. Increases network efficiency especially in high traffic environments
  * Half Duplex  
    Permits data transmission in one direction at a time. Largely obsolete. Primarily used in older networks with hubs to prevent collisions

## Frame Sizes
- MTU (Maximum Transmission Unit)  
  The largest size of a packet or frame that can be sent in a packet or frame based network  
  MTU sizes are variable. Dependent on the physical medium and network protocol with a common MTU for ethernet being 1500 bytes  
  Exceeding the MTU can result in fragmentation of packets, which can decrease network efficiency and increase latency
- Jumbo Frames  
  Refers to ethernet frams larger than the standard max of 1500 bytes. Typically up to 9000 bytes  
  Can reduce overhead and improve performance in high throughput networks. **ALL NETWORK DEVICES MUST SUPPORT THIS FEATURE** to avoid fragmentation
