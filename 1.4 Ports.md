20/21 - FTP (File Transfer Protocol)  
Allows users to transfer/modify files between client and server  
NO ENCRYPTION  
Uses port 20 for transferring file data  
Uses port 21 to administer a session 


22 - SFTP (SSH FTP)  
Utilizes SSH port 22 to encrypt data and commands for FTP  
SECURE ENCRYPTION

23 - Telnet  
Provides bidirectional communication using a virtual terminal connection.  
NO ENCRYPTION - Largely replaced by SSH for secure connections

25 - SMTP (Simple Mail Transfer Protocol)  
Primarily used for sending email messages between mail servers and sending email messages from a client device  
Retrieving emails from mail servers handled by POP3 and IMAP

587 - SMTPS (SMTP Secure)  
Uses encryption layer to enhance security of data being transferred during email communications  
Encrypts using TLS

53 - DNS (Domain Name System)  
Translates human readable domain names to IP addresses needed for locating and identifying computer services and devices with the underlying network protocols

67/68 - DHCP (Dynamic Host Config Protocol)  
Automatically assigns valid IP addresses, subnet masks, gateways, and DNS information without manual configuration  
Uses port 67 for server  
Uses port 68 for client

69 - TFTP (Trivial FTP)  
Used for transferring files smaller in size. Such as transferring boot or config files to devices like routers and switches  
NO ENCRYPTION

80 - HTTP (HyperText Transfer Protocol)  
Provides a standard for web browsers and server to communicate  
Each command is executed independently, without any knowledge of previous commands  
NOT SECURE. HTTPS is preferred

123 - NTP (Network Time Protocol)  
Provides synchronization of computer clocks over a network  
Important for ensuring logs are synchronized across the network and synchronizing time sensitive tasks

161/162 - SNMP (Simple Network Management Protocol)  
Uses for managing devices on IP networks  
Enables network admins to manage performance, find and solve network problems, and plan for network growth  
Uses port 161 for agent receiving requests  
Uses port 162 for receives SNMP notifications from agents (SNMP Traps)

389 - LDAP (Lightweight Directory Access Protocol)  
Used for accessing and maintaining distributed directory information  
Used for querying and modifying items in directory service DBs like MS Active Directory, Open LDAP...

443 - HTTPS (HTTP Secure)  
Encrypts HTTP traffic using SSL/TLS

445 - SMB (Server Message Block)  
Used by Windows systems for file sharing, network browsing, printing services, and inter-process communication  
Helps in direct IP-based communication without the need of NetBIOS

514 - Syslog  
Used to configure and manage system logs  
Sends log messages to centralized Syslog servers for monitoring and analysis

636 - LDAPS (LDAP Secure)  
Secure method of LDAP over SSL

1433 - SQL (Structured Query Language)  
Microsoft database management system

3389 - RDP (Remote Desktop Protocol)  
Microsoft protocol that enables remote connections to other computers  
Can include remote GUI connections OR remote connections to specific applications

5061/5061 - SIP (Session Initiation Protocol)  
Used for initiating, maintaining, modifying, and terminating real time sessions that involve video, voice, messaging, and other communications  
Fundamental for the operation of VoIP systems  
Operates at the Application layer and can use various transport protocols  
Uses port 5060 for UNSECURE communications  
Uses port 5061 for SECURE communications using TLS

110/995 - POP3 (Post Office Protocol)  
Retrieves emails from a server for a singular client. Downloads all the mail locally  
Uses port 995 for SECURE transfer using TLS  
Pros: Keeps a local copy on your client  
Cons: Not everything is synced across all your devices, but you can sync what is important to you   


143/993 - IMAP (Internet Messaging Access Protocol)  
Messages are stored in a remote server. Users can log in via multiple email clients on computers or mobile device and read the same messages. All changes made in the mailbox will be synced across multiple devices and messages will only be removed from the server if the user deletes the email.  
Uses port 993 for SECURE transfer using TLS  
Pros: Everything is synced all the time across all devices  
Cons: Email host server needs adequate storage for all emails  


1521 - SQLNet  
Oracle database management system

3306 - MySQL  
Open source database management system
